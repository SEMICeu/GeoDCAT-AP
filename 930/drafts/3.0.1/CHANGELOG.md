# Changelog Vocabulary with the namespace http://data.europa.eu/930

This document has been initialised on 2023-12-04 to document the vocabulary 930.
In line with the SEMIC Style Guide this publishes the supporting terms added in the context of GeoDCAT-AP.

In GeoDCAT-AP these properties or classes are used to support use-cases for which no external terms exists.
By publishing this vocabulary independently, the terms in this document can be used beyond the restrictions in GeoDCAT-AP or its extensions.

The first publication and release is on 2024-06-26.

In addition to the initial version which was based on GeoDCAT-AP 2.0.0 additional properties are included to support GeoDCAT-AP 3.0.0:
  - reference system
  - resource type
  - service category
  - service protocol
  - service type
  - spatial resolution as text
  - topic category

On 2025-10-22, the following property was added:
  - purpose
